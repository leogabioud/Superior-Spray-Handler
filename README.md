# Superior-Spray-Handler

Este es un plugin de servidor para el motor gráfico Source, diseñado para administrar y moderar los sprays de los jugadores de forma eficiente.

El proyecto está basado en el Super Spray Handler (SSH) original del foro AlliedMods, pero fue completamente unificado tomando las mejores características de otros plugins clásicos (Spray Tracer y Spray Manager). Está optimizado específicamente para funcionar en SourceForts, requiriendo exhaustivas horas de testing (QA) para depurar, enlazar los menús y limpiar el código por completo.

Para poder compilar este plugin, es necesario seguir las instrucciones del mod original:
https://forums.alliedmods.net/showthread.php?p=2410528
